# AI Personal Assistant

The current phase provides a text-based FastAPI endpoint backed by OpenAI, with a bounded tool loop for read-only workspace access, launching a small allowlist of applications, and read-only live web search through Playwright. It does not provide terminal execution, file writes/deletes, persistent conversation history, or memory.

## Requirements

- Python 3.10 or newer
- An OpenAI API key with access to the configured model

## Setup

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m playwright install chromium
Copy-Item .env.example .env
```

Edit `.env` and set `OPENAI_API_KEY` to your OpenAI API key. Choose an available model with `OPENAI_MODEL`, and set `OPENAI_TIMEOUT_SECONDS` and `ASSISTANT_WORKSPACE_ROOT` as needed. The app loads `.env` automatically; environment variables already set in the process take precedence. Keep your API key private and do not commit `.env`.

## Run

```powershell
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Send a text request:

```powershell
Invoke-RestMethod -Method Post `
  -Uri http://127.0.0.1:8000/api/assistant/message `
  -ContentType "application/json" `
  -Body '{"message":"Explain what FastAPI is in one sentence."}'
```

The response is generated by the configured OpenAI model. If OpenAI is unavailable or the API key is invalid, the endpoint returns HTTP 503 with a clear error instead of a success placeholder. Available tools can only search the live web, read UTF-8 files and list entries under `ASSISTANT_WORKSPACE_ROOT`, or launch `chrome`, `edge`, `notepad`, and `calculator` when discoverable on Windows. Web search uses a headless Chromium browser and returns up to 8,000 characters of actual page text. File reads are limited to 1 MB and directory listings to 200 entries. No arbitrary shell commands are accepted.

## Test

```powershell
python -m pytest
```

Tests verify request construction, returned model content, explicit handling of an OpenAI connection failure, the real tool-call round trip, and workspace path boundaries. They use an in-memory HTTP transport and temporary files; they do not contact an external service or launch applications.
