# AI Personal Assistant

Phase 1 provides a text-based FastAPI endpoint backed by Ollama. The model only generates a response; this phase has no computer-control tools, persistent conversation history, or memory.

## Requirements

- Python 3.10 or newer
- Ollama installed and running locally (or an Ollama-compatible server)
- A model pulled into Ollama, for example `ollama pull llama3.2`

## Setup

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
$env:OLLAMA_BASE_URL = "http://localhost:11434"
$env:OLLAMA_MODEL = "llama3.2"
```

The same settings can be exported in the shell or service environment. `.env.example` documents them; the application does not load `.env` files automatically.

## Run

```powershell
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Send a text request:

```powershell
Invoke-RestMethod -Method Post `
  -Uri http://127.0.0.1:8000/api/assistant/message `
  -ContentType "application/json" `
  -Body '{"message":"Explain what FastAPI is in one sentence."}'
```

The response is generated by the configured Ollama model. If Ollama is unavailable, the endpoint returns HTTP 503 with a clear error instead of a success placeholder.

## Test

```powershell
python -m pytest
```

Tests verify request construction, returned model content, and explicit handling of an Ollama connection failure. They use an in-memory HTTP transport and do not contact an external service.
